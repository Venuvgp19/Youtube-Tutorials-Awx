# 📚 Episode 01: AWX in 2026: what it is and is it worth learning?

**After this episode you can:** decide between AWX, Ansible Automation Platform and plain Ansible CLI.

## Overview
In this episode, we introduce **Ansible AWX** (the open-source upstream project for Red Hat Ansible Automation Platform / Tower).

## Key Topics Covered
1. What is AWX and why do you need it?
2. Architecture:
   - AWX Web UI & REST API
   - Task Engine & Receptor (Execution Nodes / Mesh)
   - PostgreSQL Backend
   - AWX Operator on Kubernetes
3. Comparison: Ansible CLI vs. AWX Web Interface.
4. Setting up our lab environment.

## Status of AWX in 2026
AWX releases have been paused since **24.6.1 (Jul 2, 2024)** during a large refactoring, so this series pins AWX 24.6.1 and AWX Operator 2.19.1. The skills carry over to Red Hat's automation controller.
